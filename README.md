# PDF Forge

**A collection of PDF and document tools for Android.**

PDF Forge brings PDF management, document conversion, scanning, and other document utilities together in one application.

> [!WARNING]
> **Beta software:** PDF Forge is still being tested. Some features may have limitations or unexpected behavior. Back up important documents before using the app.

## Features

* **PDF Management:** Merge, split, extract, remove, rotate, and organize pages.
* **PDF Compression:** Reduce PDF file sizes with configurable compression levels.
* **Document Conversion:** Convert supported document and image formats to and from PDF.
* **Document Scanner:** Scan documents using your device's camera and prepare multi-page documents.
* **OCR:** Recognize text and create searchable PDFs.
* **PDF Editing:** Use supported editing tools and visual overlays.
* **Watermarks and Page Numbers:** Add watermarks and page numbers to documents.
* **PDF Security:** Password-protect supported PDF documents.
* **PDF Viewer:** Open and preview PDF documents.
* **Additional Tools:** Explore the application for more PDF utilities.

Feature availability and output quality vary by operation and input file.

## Installation

1. Visit the [Releases page](https://github.com/akhtarsaaeem-sys/PDF-Forge/releases).
2. Download the APK attached to the latest beta release.
3. Open the downloaded APK on your Android device.
4. If prompted, allow installation from that source only if you trust the APK.
5. Follow Android's installation instructions.

**Note:** This beta is distributed outside Google Play. Only install APKs from sources you trust.

## Known Limitations

* OCR currently includes English language data only.
* Some editing operations use raster-based processing, which can affect text selection, searchability, or document quality.
* Document conversions may not preserve complex layouts, fonts, or formatting perfectly.
* PDF/A output has not been independently verified for full standards compliance.
* The signature tool creates a visual signature overlay, not a cryptographic digital signature.
* Some workflows and interactions still require testing on physical Android devices.
